Entry for the make.fun bounty **"The Worst App Idea Ever Pitched"**
([competition page](https://make.fun/bounty/u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23)).

`main.ts` is a small deterministic Node program that writes a single
sentence to `/output/entry.txt`: a deadpan pitch for a subscription app
that treats breakfast toast like a data problem worth solving — complete
with a daily photo, a butter-side-down landing prediction, and a
grandmother kept fully informed of the results.

Run it with:

```sh
node main.ts
```

The output is always the same sentence, at most 240 characters, so the
entry is byte-identical on every run.
